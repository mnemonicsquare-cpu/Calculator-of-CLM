📘 Инструкция

Для чего нужно приложение

Этот инструмент помогает:

  • Оценить, насколько сложен каждый слайд будущей CLM-презентации.
  • Спрогнозировать, сколько времени потребуется на создание прототипа всей презентации.

Вы последовательно оцениваете слайды, получаете итоговые цифры по простым, средним, сложным и особым слайдам, а затем указываете дополнительные временные факторы и получаете реалистичную оценку трудозатрат в часах и минутах.

Термин «Особый слайд» используется для слайдов, к которым не удается применить обычную классификацию по сложности. Обычно такие слайды содержат сложные механики. Предполагаемое количество времени для создания прототипа каждого особого слайда предлагается указывать отдельно.

Экран 1 — Оценка сложности слайдов

Верхние счётчики
В самом верху вы видите четыре цветных блока: Простые, Средние, Сложные, Особые. Числа в них показывают, сколько слайдов каждого типа вы уже оценили. Они обновляются автоматически при каждом добавлении, изменении или удалении слайда.

Карточка оценки слайда

  1. Название слайда — Вы можете дать слайду понятное имя (например, «Слайд 5 — Механизм действия»). По умолчанию подставляется «Слайд брифа 1», «Слайд брифа 2» и т.д. Название можно редактировать в любой момент.
  2. Вопросы о слайде — Для каждого слайда вы отвечаете на три вопроса:
    • Количество видов слайда — выберите 1, 2, 3–4 или 5 и более. Если выбрано «5 и более», появится поле для точного числа видов.
    • Анимация — Нет / Простая (последовательное появление) / Сложная (механизм действия, перетаскивание). Важно: если выбрано «5 и более видов» и указана анимация, появятся поля для количества видов с анимацией.
    • Механика — Нет / Простая (калькулятор, опрос) / Сложная (многоэтапный расчёт). Если механика сложная, слайд сразу считается Особым (почасовая оценка). При простой механике и «5 и более видов» появится поле для количества видов с механикой.
  3. Кнопка «Рассчитать сложность» — показывает результат: тип слайда или распределение по сложности.
  4. Добавление слайда — после расчёта появляется кнопка «Добавить слайд в список». Нажмите её, чтобы сохранить оценку.

Список оценённых слайдов
Ниже находится прокручиваемый список. Каждый слайд можно редактировать (иконка карандаша) или удалить (крестик). При удалении потребуется подтверждение.

Переход к расчёту времени — кнопка «Завершить расчёт сложности слайдов» внизу экрана.

Экран 2 — Расчёт времени

В верхней части таблица с нормативами и итоговым временем по каждому типу. Особые слайды можно переименовывать и вводить для них индивидуальное время. Отсутствующие типы не отображаются.

Дополнительные факторы — блок под таблицей. Изначально содержит фактор «Поиск и анализ информации». Можно добавить неограниченное количество своих факторов, переименовывать их. Для каждого фактора выбирается режим:

  • Посчитать отдельно — время добавляется отдельной строкой. Можно распределить по слайдам (тогда нормативы увеличатся).
  • Посчитать на слайд в среднем — указывается среднее время на слайд, нормативы пересчитываются.

Все изменения мгновенно влияют на общее время.

Кнопка «Создать отчёт» — показывает текстовый отчёт для копирования.

Кнопка «Завершить расчёты» — сбрасывает все данные и возвращает к началу.

Кнопка «Назад» — возвращает к списку слайдов.

Тёмная тема — переключатель в верхней части каждого экрана.
